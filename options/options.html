SuperN

Time block

per-site limits. set a daily minute budget, a window when the site is blocked, or both. hard mode blocks outright; soft shows a reminder with an override button. resets at 4am local time.

on domain min/day block window mode used

window blocks the site during the given range (wraps midnight if end is before start). leave both blank to skip. wkdys applies the window Mon–Fri only — the daily budget still counts every day. Turn a rule off to pause it without losing its settings.

Snoozed tabs

tabs scheduled to reopen later. right-click any tab → snooze tab.
